# Décisions d'architecture (ADR)

Chaque décision structurante fait l'objet d'un fichier `NNNN-titre-court.md`, selon le modèle ci-dessous.
Une décision n'est jamais modifiée après validation : si elle change, une nouvelle ADR la remplace (statut « Remplacée par NNNN »).

## Modèle

```markdown
# NNNN — Titre

- **Statut** : Proposée | Acceptée | Remplacée par NNNN
- **Date** : AAAA-MM-JJ

## Contexte
Pourquoi une décision est nécessaire.

## Décision
Ce qui est décidé.

## Conséquences
Ce que cela implique, y compris les inconvénients assumés.
```
